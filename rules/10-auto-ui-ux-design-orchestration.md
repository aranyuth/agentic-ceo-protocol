# 🎨 Universal Auto UI/UX Design Orchestration Protocol
# 🎨 กฎเหล็กสากล: ระบบระดมสกิลออกแบบ UI/UX อัตโนมัติ (Zero-Cognitive Load Protocol)

## 📌 Core Philosophy / ปรัชญาหลัก
> **"Zero Cognitive Load for the User / ผู้ใช้ไม่ต้องจำศัพท์เทคนิคและไม่ต้องท่องชื่อสกิล"**
> 
> The user is the Decision Maker / CEO, not a UX/UI designer or a skill librarian. The user must **NEVER be expected to memorize or type 25 individual design skills** (e.g. `ui-ux-pro-max`, `theme-factory`, `emil-design-eng`, `antislop-ui`).
>
> Whenever the user mentions creating, designing, styling, or refactoring any web page, landing page, dashboard, HTML layout, mobile screen, or frontend component—even in plain everyday Thai/English—the agent must **AUTOMATICALLY orchestrate the 4 Core Design Pillars silently in the background**.
>
> ผู้ใช้งานคือผู้ตัดสินใจปลายทาง ไม่ใช่นักออกแบบและไม่ใช่บรรณารักษ์ที่ต้องคอยจำชื่อสกิลยิบย่อย เมื่อใดก็ตามที่มีคำสั่งสร้างหน้าเว็บ ทำหน้าบ้าน หรือเขียน UI ด้วยภาษาพูดธรรมดา AI ต้อง **ดึง 4 เสาหลักดีไซน์มาทำงานร่วมกันเบื้องหลังโดยอัตโนมัติ 100% ทันที**

## 2. 🏛️ The 4 Core Design Pillars (4 เสาหลักระดมพลังอัตโนมัติ)
ทุกครั้งที่ลงมือสร้างหรือแก้ไขหน้าเว็บ AI ต้องผสานความสามารถของ 4 สกิลนี้โดยอัตโนมัติ:

### 1. 📐 Design System & Typography (`ui-ux-pro-max`)
- กำหนดสไตล์ที่ชัดเจน (เช่น Minimal Tech, Apple Clean, Stripe Professional, หรือ Warm Editorial)
- ใช้คู่ฟอนต์คุณภาพสูงเสมอ (เช่น `Plus Jakarta Sans`, `Inter`, `Geist`, `Noto Sans Thai`)
- จัด Visual Hierarchy (H1 ใหญ่เด่นชัด, Body สบายตา, Caption ชัดเจน) และเว้น Spacing ให้โปร่ง

### 2. 🎨 Color Token Locking (`theme-factory`)
- **ห้ามสุ่มสี Tailwind ทั่วไป:** ล็อคชุดสี HEX ประจำโปรเจกต์ตั้งแต่บรรทัดแรก เช่น:
  - Background: `#090d16` หรือ `#fafafa`
  - Surface/Card: `#111827` หรือ `#ffffff`
  - Border: `rgba(255,255,255,0.08)` หรือ `#e5e7eb`
  - Accent/Brand: เลือกสีหลัก 1 สี ไม่ใช้สีรุ้ง

### 3. 🛡️ Strict Anti-AI-Slop Filter (`antislop-ui`)
- **บล็อกดีไซน์ขยะแบบ AI 100%:**
  - ❌ ห้ามใช้ปุ่มสีม่วงเกรเดียนต์สำเร็จรูป (Purple-Indigo Gradient)
  - ❌ ห้ามใช้การ์ด 3 ใบลอยกลางจอแบบซ้ำซาก
  - ❌ ห้ามใช้ข้อความ Placeholder เพ้อฝัน (เช่น "Empower your journey with synergy") ให้ใช้ข้อความเชิงธุรกิจที่สื่อสารตรงไปตรงมา

### 4. ✨ Emil Kowalski Finish Gate (`emil-design-eng`)
- **ต้องผ่านรอบขัดเกลาก่อนส่งมอบทุกครั้ง (Mandatory Polish):**
  - **Micro-interactions:** ปุ่มทุกลูกต้องมี `active:scale-[0.98] transition-transform duration-100`
  - **Subtle Borders:** ใช้เส้นขอบบาง 1px ที่เนียนตา (`border-white/10` หรือ `border-zinc-800`) แทนกรอบหนาเทอะทะ
  - **Breathing Room:** ให้ระยะ Padding ที่กว้างพอ ห้ามวางองค์ประกอบเบียดกัน

## 3. 🚀 Zero-Slop Delivery Standard (เกณฑ์การส่งมอบงาน)
- **Single-Turn Production Ready:** ส่งมอบโค้ด HTML/Tailwind/React ที่สมบูรณ์ รันได้ทันที ไม่ทิ้ง `<!-- TODO -->` หรือปล่อยให้ผู้ใช้ต้องมาทวงถามเรื่องความสวยงาม
- **Sensory Evidence:** แนบตัวอย่างและลิงก์ไฟล์ที่ผู้ใช้สามารถคลิกเปิดดูบนเบราว์เซอร์ได้ทันที
