PARADIGM SHIFT

Micromanager vs. Autonomous Judge

❌
Human-in-the-Loop (Legacy)
High-friction bottleneck
  • 🛑 Blocks execution on trivial reversible steps (asking "Should I write this file?").
  • 🛑 Dumps testing back on the human ("Please run localhost and check if button works").
  • 🛑 Drip-feeds minimum code, forcing you to prompt 5 more times for basic polish.
  • 🛑 Wastes costly frontier tokens on raw directory globbing and log reading.
⚡
Human-as-a-Judge (CEO Protocol)
Zero-bottleneck executive velocity
  • ✅ Proceed, then present: Autonomous end-to-end execution on all reversible actions.
  • ✅ Prove It Works: Runs automated verification scripts, asserts green before delivery.
  • ✅ Zero Drip-Feeding: Pre-emptively builds shortcuts, responsive edges, and error states.
  • ✅ 3-Tier Cognitive Routing: Flash (Scout) ➔ Pro (Workhorse) ➔ Opus (Deep Architect).

CORE DIRECTIVES

The 8 Universal Rule Modules

RULE 01

Human-as-a-Judge Protocol

Never block on the human for reversible actions. Prove it works with real verification scripts. Zero drip-feeding with pre-ship self-expansion.

RULE 02

3-Tier Smart Model Routing

Allocate cognitive budget strictly: Flash for speed scouts & raw globbing, Pro for standard features & bugfixes, Opus/Frontier for deep architectural reasoning.

RULE 03

Parallel Subagent Swarm

Break multi-component engineering into concurrent specialist subagents (scraper, database architect, frontend commander, security reviewer) in parallel.

RULE 04

Credentials & File Safety

Strict zero-credentials policy in chat prompts. Use .env configs. Never silently overwrite source data; enforce non-destructive versioning (_v1, _v2).

RULE 05

Live Deploy & Linked Commits

Never finish a task without real proof. Auto-deploy frontend builds to live preview URLs and pair git commits with clickable repository hyperlinks.
